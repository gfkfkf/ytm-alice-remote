# ytm-alice remote

Неофициальный Android-пульт для [ytm-alice](https://github.com/SPAWNRYS-ban/ytm-alice) —
автономного YouTube Music для Яндекс Станции.

Музыка по-прежнему звучит на колонке. Приложение открывает встроенную веб-панель
ytm-alice (`http://IP_СТАНЦИИ:24721`) в нативном окне: поиск, очередь, лайки,
плейлисты, вход в аккаунт и настройки — всё, что есть в панели.

## Возможности

- экран первого запуска: адрес Станции с проверкой подключения (`/api/info`);
- автопоиск Станции в локальной сети: `alice.lan`, `alice.local` и перебор адресов
  своей подсети на порту `24721`;
- сохранение адреса, автоподключение при следующем запуске;
- загрузка `cookies.txt` из системного файлового менеджера (выбор файла в панели);
- индикатор связи, экран ошибки с повторной попыткой и сменой адреса;
- меню: переподключиться, сменить адрес, открыть в браузере, о приложении;
- внешние ссылки (например, `google.com/device` для входа по коду) открываются
  в браузере;
- тёмная тема, иконка проекта, APK без интернета-зависимостей и аналитики.

## Требования

- Android 6.0 (API 23) и новее;
- телефон и Станция в одной локальной сети;
- на Станции установлен и запущен ytm-alice (панель отвечает на `/api/info`).

## Установка

Готовый APK: `dist/ytm-alice-remote-1.0.0.apk`.

1. Передайте файл на телефон и откройте его (разрешите установку из неизвестных
   источников для файлового менеджера/браузера).
2. На первом экране введите адрес Станции, например `192.168.1.50:24721`,
   либо нажмите «Найти Станцию в сети».
3. «Подключиться» — откроется панель.

## Сборка

Нужны JDK 17+ и Android SDK с `build-tools` и `platforms/android-34`.
Gradle не требуется: сборка идёт напрямую через `aapt2`, `javac`, `d8`,
`zipalign`, `apksigner`.

```powershell
# из корня проекта
powershell -ExecutionPolicy Bypass -File .\build.ps1 -VersionName 1.0.0 -VersionCode 1
```

Скрипт сам находит JDK (`JAVA_HOME`, портативный Android Studio) и SDK
(`ANDROID_HOME`, `%LOCALAPPDATA%\Android\Sdk`), при первом запуске создаёт
ключ подписи `keystore/ytm-alice-remote.jks` (пароль `ytmalice`) и кладёт
подписанный APK в `dist/`.

**Важно:** сохраните `keystore/ytm-alice-remote.jks` — обновления должны быть
подписаны тем же ключом, иначе Android не установит их поверх старой версии.

Параметры скрипта: `-VersionName`, `-VersionCode`, `-Keystore`, `-KeyAlias`,
`-StorePassword`, `-KeyPassword`. Для публикации используйте свой ключ.

Иконки пересобираются скриптом `tools/make-icons.ps1` (System.Drawing), если
их нет в `res/mipmap-*`.

## Проверка без Станции

В репозитории есть мок веб-панели, который отдаёт настоящие файлы панели и
заглушки API:

```powershell
git clone --depth 1 https://github.com/SPAWNRYS-ban/ytm-alice.git ..\ytm-alice
python tools\mock-panel.py --web ..\ytm-alice\source\web --port 24721
```

С эмулятора адрес панели — `10.0.2.2:24721`, с телефона — IP компьютера.

## Как это работает

Приложение — тонкая нативная оболочка (WebView) вокруг веб-панели:

- `MainActivity` — экран настройки, WebView, меню, выбор файла cookies,
  обработка ошибок загрузки;
- `StationFinder` — параллельный опрос `/api/info` по адресам локальной сети;
- `normalize()` — принимает `192.168.1.50`, `alice.lan`, `host:port` или полный
  URL и приводит к `http://host:24721`;
- cleartext HTTP разрешён манифестом (`usesCleartextTraffic`), так как панель
  работает по HTTP внутри доверенной локальной сети.

## Ограничения

- Само приложение не воспроизводит музыку: это пульт, звук идёт с колонки.
  Трансляция с телефона через значок Cast в YouTube Music поддерживается
  самим ytm-alice и от этого приложения не зависит.
- Панель не использует пароль и доступна всем в локальной сети — так задумано
  в ytm-alice.
- Если панель открывается по собственному домену, добавьте его в настройках
  панели («Домены панели»), иначе сервер отклонит запрос (403).
- targetSdk 34 выбран для установки APK вручную. Для Google Play потребуется
  targetSdk 35+ и политика конфиденциальности.
